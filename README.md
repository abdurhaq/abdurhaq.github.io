# Abdur Rahman — Portfolio

Personal portfolio website, live at **https://abdurhaq.github.io**.

A dependency-free static site (HTML, CSS, vanilla JS) with Apple-inspired design:
scroll-linked animations, word-by-word text reveal, light/dark themes, live GitHub
repositories, and a working contact form (via FormSubmit).

## Run locally

```bash
python -m http.server 5500
# then open http://localhost:5500
```

## Updating content

- Text and links live in `index.html`.
- Replace `assets/Abdur-Rahman-Resume.pdf` to update the downloadable resume.
- Push to `main` and GitHub Pages redeploys automatically.
