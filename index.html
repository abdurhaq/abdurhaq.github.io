Natural Language Processing

Sentiment Analysis Web App

A DistilBERT transformer fine-tuned to read the mood of any sentence, served in a real-time web app with confidence scores and analysis history.

  • Fine-tuned DistilBERT on 67,000+ sentences from the Stanford SST-2 dataset using HuggingFace Transformers and PyTorch.
  • Reached 91%+ validation accuracy with GPU-accelerated training, mixed precision and early stopping.
  • Interactive Streamlit app with real-time predictions, confidence scores and analysis history.
  • Trained model hosted on the HuggingFace Hub; live app deployed on Streamlit Cloud.

Healthcare · Explainable ML

Diabetes Risk Prediction System

An end-to-end ML pipeline that estimates a person’s diabetes risk — and uses SHAP to explain exactly why it made each prediction.

  • Built an end-to-end pipeline and benchmarked four models: Logistic Regression, SVM, Random Forest and XGBoost.
  • Random Forest achieved 77% accuracy and 0.83 ROC-AUC.
  • Deployed as a Streamlit app with SHAP explainability for every prediction.
